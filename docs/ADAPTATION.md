## 6. Bug Reproduction Specifications (M0 Baseline)

### Bug F1: Month-End Stepping Drift (Red)
* **File:** `src/domain/schedules/scheduleHelper.ts` line 88.
* **Mechanism:** `resultDate.setUTCMonth(resultDate.getUTCMonth() + 1)`. When `payDate` is 31 Jan, JavaScript advances month to February. Because February has only 28 days (or 29 in leap years), date overflows to 2 or 3 March. On the subsequent month, advancing month from March 3 gives April 3, permanently losing the month-end anchor.
* **Repro Case:** Anchor `2026-01-31`. Month 1 should be `2026-02-28`. Month 2 should be `2026-03-31`. Month 3 should be `2026-04-30`. Currently yields `2026-03-03`, `2026-04-03`, `2026-05-03`.

### Bug F2: Server Timezone Day Shift (Red)
* **File:** `src/app/api/forecast/route.ts`, `src/services/ai/aiInsights.ts`.
* **Mechanism:** Routes instantiate `new Date()`. When executed on a UTC cloud runtime (e.g. Vercel) between 00:00 UTC and 11:00 UTC (11:00 AM AEDT), the UTC calendar day is yesterday in Sydney.
* **Repro Case:** Server at `2026-10-15T02:00:00.000Z` evaluates Sydney time as `2026-10-15T13:00:00.000+11:00` (15 Oct), but `new Date()` gives `2026-10-15T00:00:00.000Z` only if correctly normalized via `sydneyToday()`.

### Bug F6: Google Auth Missing Buffer Default & Image (Green)
* **File:** `prisma/schema.prisma` line 67.
* **Mechanism:** `User.buffer` is defined as `Int` without `@default`. Auth.js Prisma adapter creates new OAuth users with only `{ name, email, image }`. Prisma throws an invariant violation: `Field 'buffer' is required`. Furthermore, standard adapter user schema expects `image String?`, which `User` currently lacks.
* **Repro Case:** Attempting `prisma.user.create({ data: { email: "test@gmail.com", name: "Test" } })` throws required field error.

### Bug F7: Split Pay Duplication of Baselines & Commitments (Green)
* **File:** `src/domain/engine/timelineGenerator.ts` lines 84–116.
* **Mechanism:** In the timeline generator loop: `inflows.forEach(inflow => { commitments.forEach(...); baselines.forEach(...); })`. If a user receives their salary in two deposits on the same day (or split across the pay cycle), all baselines and commitments are added to the timeline twice.
* **Repro Case:** User with 2 inflows of $1,200 and a baseline of $210 has $420 deducted in the window instead of $210.
